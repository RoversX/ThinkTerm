# `win32_acrylic_accent_color = COLOR`

{{since('20230712-072601-f4abf8fd')}}

When the *Acrylic* backdrop is used on Windows systems earlier than build
22621 (including the default `win32_system_backdrop = "Auto"` on a see-through
window), this option specifies the accent color used with the legacy
*Acrylic* composition effect.

See also [win32_system_backdrop](win32_system_backdrop.md).
