# Legacy upstream workflows

These 44 files are WezTerm's original GitHub Actions workflows, inherited when
ThinkTerm was forked. They are parked here rather than deleted so the history
and the recipes stay available.

GitHub only executes workflows that live in `.github/workflows/`, so nothing in
this directory runs. They were already inert before the move — commit `3289fee`
replaced every trigger block with a bare `workflow_dispatch:` and left the
original triggers as comments — but they still occupied 44 slots in the Actions
sidebar and Dependabot kept opening PRs against them.

## What is in here

| Family | Purpose | Count |
| --- | --- | --- |
| `gen_<os>.yml` | pull request check: build + test, no packaging | 11 |
| `gen_<os>_continuous.yml` | nightly: build, package, upload to the `nightly` release | 11 |
| `gen_<os>_tag.yml` | tagged release: build, package, create pre-release, upload | 11 |
| `nix*.yml`, `pages.yml`, `termwiz.yml`, `wezterm_ssh.yml`, `fmt.yml`, … | assorted upstream CI | 10 |
| `thinkterm-windows-x64-portable.yml` | ThinkTerm's own Windows artifact build | 1 |

The `gen_*` files are generated by `ci/generate-workflows.py` from a target
table; they are not meant to be hand-edited upstream.

## Notes for anyone mining these for recipes

- The packaging itself lives in `ci/deploy.sh` and `ci/appimage.sh`, not in the
  workflows. The macOS and Windows paths in those scripts are ThinkTerm-branded;
  the Debian and RPM paths still build packages named `wezterm`.
- Every Linux target runs in a container on `ubuntu-latest`, so none of these
  depend on a matching hosted runner image being available.
- The `cargo vendor --locked --versioned-dirs >> .cargo/config` step in these
  files is a no-op. This repo's real config is `.cargo/config.toml`, which takes
  precedence, so the vendored source replacement is never applied.
- `git config --global --add safe.directory /__w/wezterm/wezterm` hardcodes the
  upstream repo name; under this fork the path is `/__w/ThinkTerm/ThinkTerm`.
  Use `$GITHUB_WORKSPACE` instead.

## Restoring one

```bash
git mv ci/legacy-workflows/gen_macos_tag.yml .github/workflows/
```
